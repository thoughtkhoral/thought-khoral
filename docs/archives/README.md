# Development evidence archives

These archives preserve historical review artifacts that were generated in
temporary worktrees. They are provenance, not current implementation plans or
product specifications; use the accepted `.ai/specs/` documents and each
project's `main` branch for current behavior.

## A2A agent gateway foundation (2026-09-21)

[`a2a-agent-gateway-foundation-2026-09-21.tar.gz`](a2a-agent-gateway-foundation-2026-09-21.tar.gz)
contains the 46 original Markdown briefs/reports and diff snapshots from the
seven-task review. The files retain their original relative paths under
`2026-09-21-a2a-agent-gateway-foundation/`. The archive is intentionally
compressed because the diff snapshots contain nearly 50,000 lines of
historical intermediate code and whitespace that should not be treated as a
fresh source patch. The final integrated source lives in the project
repositories' `main` branches.
